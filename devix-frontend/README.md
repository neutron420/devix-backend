# Devix Frontend

This is the official Next.js web application frontend for **Devix**, a developer community platform. It connects to the Go-based Devix Backend API.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State/Data Fetching**: React Server Components & Client Fetching

---

### 1. Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18+ recommended) and `npm` installed.
